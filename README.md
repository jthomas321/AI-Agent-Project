# AI-agent-project
Abstract: Sweetery is a multi-agent system consisting of six agents, a natural language processing agent (NLP agent), a research agent, a price prediction agent, a recommendation agent, a checking agent, and a ranking agent. Users specify their preferred dessert type, flavor, and optional cost through a Streamlit interface. The system returns the top three dessert recommendations in Cookeville, TN, displaying dessert names, business names, source links, and extracted or estimated prices. The project's GitHub repository with results, source code, and set up instructions can be found in references.
